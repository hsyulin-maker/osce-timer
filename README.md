# OSCE 考官計時器

第 5 版・兒童醫院風格。為考官在手機上操作設計，繁體中文、大字倒數，搭配柔和配色與純 CSS 小熊、雲朵和星星。

## 計時流程

- 首站先讀題 1 分鐘。
- 作答 8 分鐘；經過 7 分鐘，提醒剩下 1 分鐘。
- 作答時間到轉紅，接續回饋 2 分鐘。
- 換站與閱讀下一題共 1 分鐘，另計，不包含在作答與回饋的 10 分鐘內。

支援開始、暫停、重設、提示音、可選語音、全螢幕，以及瀏覽器支援時的螢幕常亮。考站與學員可自行設定。倒數依實際經過時間計算；重新載入可恢復進度。

## 本機使用

無須安裝前端套件。在此資料夾執行：

```sh
python -m http.server 8000
```

瀏覽器開啟 `http://localhost:8000`。也可直接開啟 `osce-timer-standalone.html` 單一檔案版。

手機使用時請確認裝置音量並保持頁面開啟；背景或鎖定螢幕時，聲音可能受到系統限制。

## 發布

本專案是純靜態網站，內含 Vercel 設定：Framework 選 Other，不需 Build Command，Output Directory 為 `.`。
